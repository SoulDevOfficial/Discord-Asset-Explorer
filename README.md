Opens a easy-to-read menu displaying all loaded assets!

# How To Use
Open your developer tools (ctrl + shift + i) and paste the code from the [explorer.js](/explorer.js) file. You may need to type in `allow pasting` to allow the script. Once you paste it, the menu should automatically open up! Keep in mind that it may be a bit slow on lower end devices. If you accidentally closed it, you can send `window.openSoulExplorer();` in the console to quickly open it up again without pasting the code again!
